# 坦克大战 · Tank Battle

一个用原生 HTML / CSS / JavaScript（Canvas）编写的经典坦克大战小游戏，单文件 `index.html`，双击即可游玩。

## 玩法

- 控制己方坦克，摧毁所有敌方坦克即可过关。
- 保护地图底部的**基地（老鹰）**——基地被击毁即游戏结束。
- 破坏砖墙、绕开钢板、跨越水域、利用草丛隐蔽。
- 收集敌人掉落的道具获得加成。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |

移动端会自动显示触屏按钮。

## 道具

| 图标 | 效果 |
| --- | --- |
| `S` | 护盾：短暂无敌 |
| `+` | 生命 +1 |
| `R` | 连射：射速提升、可双弹 |
| `B` | 炸弹：清除场上所有敌人 |

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。

或者启动一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
